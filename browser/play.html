Opening a folder from this page

Folder access is available in this browser. If the button still does nothing:

  • Allow the prompt the browser shows after you pick the folder ("View files" / "Edit files").
  • Pick the game's own folder, not a system folder such as Program Files itself, your user folder or a whole drive: browsers refuse those.
  • If the browser says it “can't open this folder because it contains system files”, the game is installed in a protected place (Steam puts it under Program Files). Use compatibility mode instead: it works there, but the browser does not remember the folder, so you choose it again each time you launch.
  • If you blocked it before: click the icon left of the address, open the site settings and reset the file permissions.
